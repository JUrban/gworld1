## Scope and proof audit

The original complete nilpotent page and exact N8 paragraph were
inspected earlier, including the rendered statement. Evidence remains
in `research/statement-audits/N8/`. Part (a) has a prior negative answer
and is separate. Part (b) asks about every finitely generated free
nilpotent group. The present extension covers every target in class
seven in every finite rank, not arbitrary nilpotency class.

The all-rank argument replaces the earlier rank-two dimension bound
with a classification. For nonzero z in L1 and D in L4, the kernel of
`(U,V) -> [U,D]+[z,V]` on L2+L5 is nonzero precisely when
`D=(ad_z)^2 T` for some nonzero T in L2. It is then the one-dimensional
line generated by `(T,-[T,[z,T]])`. Rational T need not be integral;
the algorithm computes the full integral affine lattice separately.

The proof uses a homogeneous free generating set for the derived Lie
algebra. The required homogeneous form of Shirshov's lemma is stated
explicitly in the archived Bryant–Kovacs–Stohr primary source, printed
pp.147–148. Only its ordinary characteristic-zero assertion is used.
The degree-five metabelian kernel is proved by the polynomial-syzygy
description and Witt dimensions. The degree-six direct decomposition
then supplies the tensor projections and the separate (2,3) Nielsen
kernel. Adding a term from [L2,L2] to `(ad_z)^2 T` must destroy the
first kernel unless the term is zero; this is part of the proof and
also a negative computational control.

The group algorithm retains all integral leading scales and all exact
Nielsen residues. The move is x->yx, with y fixed. The new (2,2)
leading type has an injective first correction and a joint linear
tail. For type (1,4), the remaining parameter is a single integer;
the proof bounds its last obstruction by an integer-valued quadratic.
Several generators in L2 introduce nonlinear terms in weight four,
whose interaction with the base weight-four factor lies beyond class
seven. The final degree-seven lattice is independent of the parameter.

The existing quadratic-lattice procedure checks free equations over
the integers and torsion congruences. Bounded group samples support,
but do not prove, the polynomial degree bound or completeness.

## Arithmetic implementations

The prototype is `scripts/n8_class7.py`. It uses the prior Hall/Magnus
representation and finite leading-factor algorithms. New larger
integer systems use python-flint 0.9.0 Hermite transformations. For
row matrix B the code checks H=U*B and det(U)=+/-1. The zero rows of
H give the full integral kernel via the corresponding rows of U.
Integer divisibility at the nonzero pivots decides membership.

An LLL basis is used only to shorten an existing solution modulo this
kernel. Its integer unimodular transformation is checked exactly,
and nearest-plane subtraction uses exact rational arithmetic. No
floating-point result decides mathematical membership. Polynomial
lattice certificates still use the existing exact Smith decomposition.

`scripts/n8_fast_magnus.py` implements the same truncated integer
convolution, grouping the second factor's monomials by degree so
that pairs beyond the truncation are skipped in bulk. It does not
change collection, Hall generators, or any decision procedure.

## Reproduction

The environment versions are in `provenance/research-tools.md`. These
commands reproduce the successful target suite and translate its saved
certificates without doing further mathematical work during export:

```sh
python3 scripts/run_recorded.py --name n8-class7-all-rank-checks-v3 \
  --cores 1 --memory-gb 8 --timeout 600 --expect 'PASS N8 all-rank class7' \
  -- .venv/bin/python scripts/check_n8_class7_all_rank.py
.venv/bin/python scripts/export_n8_class7_all_rank_gap.py
python3 scripts/run_recorded.py --name n8-class7-all-rank-gap-v1 \
  --cores 1 --memory-gb 8 --timeout 600 --expect 'PASS N8 all-rank class7 GAP' \
  -- bin/gap -q --quitonbreak scripts/check_n8_class7_all_rank_gap.g
```

The target generator refuses to overwrite `checks.json`; regenerate
in a separate work copy, and use fresh result names. The preliminary
checks' exact commands, seeds, bounds, timings and raw log hashes are
in their `results/NAME/process.json` files and checker scripts.
Certificates, including Hall words, are stored in
`research/certificates/N8-class7-all-rank/`.
