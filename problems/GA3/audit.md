## Proof challenges checked

| Potential defect | Resolution in the written argument |
| --- | --- |
| Lambda need not have a maximal proper convex subgroup | Restrict to the convex subgroup generated by a specifically chosen positive L. |
| Collapsing at an arbitrary basepoint scale might give a fixed point | L is the maximum translation length of generators and their two-letter products. An element with length L survives. |
| Distances between generator axes might be much larger than their lengths | Two-letter products detect the bridge lengths. Helly and axis projection supply a basepoint with generator displacements at most 3L. |
| The published collapse fact might apply only to finite-dimensional real length groups | Guirardel's explicit remark after Fact 5.1 covers every Lambda and every convex subgroup. |
| Filling Archimedean segments might introduce bad stabilizers | Divisible scalar extension makes the old length group dense; segment filling creates no branch points, and every new fixed arc/tripod contains an old one. |
| The collapsed action might preserve a line or an end | Either possibility produces an abelian normal kernel. CSA and nonabelianness rule this out. |
| Boundary action might have nontrivial elements fixing large sets | Three fixed ends would give a pointwise fixed nondegenerate tripod. |
| Big-powers property assumed merely from CSA | Not used. The separating element is chosen using a concrete real-tree boundary action. |
| A separating map on a finitely generated subgroup might not extend to G | Both factor maps are identity or conjugation, so the same formula extends to all G. |
| One-word separation might not imply simultaneous separation | All syllables enter the same finite set C; the same h and N work throughout. |
| A reduced word might begin and end in the same factor | Cyclic reduction and conjugacy reduce it to one factor or an even alternating core. |

The elementary tree facts and imported boundary facts still require
specialist scrutiny. There is no formal proof assistant verification.

## Exact computational controls

These checks concern the already known free-group case only. They
cannot verify the non-Archimedean collapse, CSA argument or full theorem.

`scripts/ga3_free_square_controls.py` uses integer-letter free-word
reduction in Python 3.12, with no random choices. In F(a,b), put

    p = a^5 b a b^2 a,
    h = p a b p^(-1),
    U+ = cylinder(p a), U- = cylinder(p b^(-1)).

For all 160 nonidentity words c of length at most four, an oriented
edge calculation verifies that c cylinder(p) is disjoint from
cylinder(p). An exact finite partition of each complementary boundary
cylinder verifies 46 cone inclusions in total, proving the two
north-south inclusions already for n=1 in this example. These are
checks of entire boundary cylinders, not sampled ends.

Independently of the cone calculation, every nonidentity word of
length at most four in F4 = F2*F2 survives Phi_1 and Phi_2: 3,200
inputs and 6,400 images. Python saves the exact reduced images in
`research/certificates/GA3-free-square/certificate.json`. GAP 4.16.1
independently generates that complete ball and tests the image maps
using native free groups. It verifies nontriviality, not the equality
of every saved Python image. GAP does not replay the cone partition.

Negative controls use h=a and the cross-factor commutator of a,
which is killed for n=1,2,7. A separate Z target kills the cross
commutator for all 49 pairs of slopes in [-3,3]. These exhibit the
need for the separator choice and the nonabelian scope.

Recorded commands (one CPU, 4 GB, 120-second limit each):

```sh
python3 scripts/run_recorded.py --name ga3-free-square-controls-v2 --cores 1 --memory-gb 4 --timeout 120 --expect 'PASS GA3 free-square controls' -- .venv/bin/python scripts/ga3_free_square_controls.py
```

Final Python and GAP jobs passed with empty stderr in 0.170 and 1.874
seconds. The first Python job also passed. The first GAP job reached

directory; the corresponding Python source and certificate are also
