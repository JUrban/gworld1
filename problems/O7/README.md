(O7) Let G be the direct product of two
copies of the free group F_n, n \ge 2, generated by {x_1,...,x_n} and

(a) Is it true that every generating system of cardinality 2n
of the group G is Nielsen equivalent to {(x_1,1),...,(x_n,1),
(1,y_1),...,(1,y_n)} ?

Is it true that for every generating system of cardinality 2n, there is
k \ge 0 such that this generating system, augmented by
(x_{n+1},1),...,(x_{n+k},1), (1,y_{n+1}),...,(1,y_{n+k})
is Nielsen equivalent to {(x_1,1),...,(x_{n+k},1),
(1,y_1),...,(1,y_{n+k})} ?
