(E4) (J.Birman) Let F = F_n be the free group of rank n generated by
a_1,...,a_n. Is there a solution of the equation y_1 a_1 y_1^{-1} ... y_n
a_n y_n^{-1} = a_1...a_n with all y_i from the second commutator subgroup
F'' ? (The answer is "no" if and only if the Gassner representation of
the pure braid group P_n is faithful -- cf. problem
(B2)).
