(F42) (V. Dotsenko) Let S_n denote the set of all elements of length n in a free group F_r, and B_n the set of all elements of length \le n.
(a) What is the largest number of elements from S_n that freely generate a subgroup of F_r?
(b) The same question for elements from B_n.
