(O1) The Andrews-Curtis conjecture. Let
F = F_n be the free group of a finite rank n with a fixed set X = {x_1,...,x_n}
of free generators.
(a) A set Y = {y_1,...,y_n} of elements of F generates
the group F as a normal subgroup if and only if Y is Andrews-Curtis
equivalent to X, which means one can get from X to Y by a sequence of
Nielsen transformations
together with conjugations by elements of F.
(b) The same conjecture if one allows one more transformation,
"stabilization", where X is extended to {x_1,...,x_n, x_{n+1},...},
and its converse.
