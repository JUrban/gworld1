# F20: bounded rewriting probes, no new conclusion

28 September 2026, approximately 14:20–14:25 UTC. The full original
free-group page and linked background were read. The exact F20 paragraph
was rendered and visually inspected. The problem asks whether gamma_c
of a finite-rank free group is normally generated by the basic
commutators of **exactly** weight c. A result using additional weights
does not answer that question.

## Prior source and scope

Archived and read the full ten-page author PDF by Moravec and Morse,
*Basic commutators as relations: A computational perspective*,
Contemporary Mathematics 511 (2010), 83–92,
[DOI 10.1090/conm/511/10043](https://doi.org/10.1090/conm/511/10043).
The [author-hosted PDF](https://users.fmf.uni-lj.si/moravec/Papers/mmpaper.pdf)
is archived as `literature/raw/F20-Moravec-Morse-computational.pdf`, SHA-256
`df8300bc347532b5e6b014c8eeb3675e4713460e5892d714716fbf851c57cb32`.

The source records the known cases through weight five. Its computational
method introduces lower-weight commutators as generators and reverses
their order before recursive Knuth–Bendix completion. It explicitly
reports no progress on rank two, weight six. Theorem 1 concerns Hall-order
independence through weight nine, not a solution in all those weights.
Proposition 2 reduces a fixed weight to finitely many ranks.

Jackson's 2008 paper *Basic commutators in weights six and seven as
relators*, [publisher page](https://doi.org/10.1080/00927870802108148),
uses weights six **and seven** in rank two. Its primary abstract was
checked; its full text was not obtained. The attempted CiteSeer download
with DOI key `9d618c9b5e439fc6efd065fb6fabecc4f6aa6297` returned 404.
No claim about current full openness follows merely from the dates
of these sources.

## Reproducible bounded probes

`scripts/probe_f20_rewriting.g` enumerates the Hall commutators on two
generators through weight c+1, adds generators for weights below c,
and imposes the definitions and weight-c relators. It uses KBMAG's
recursive ordering, reversing the Hall generator order. Every reported
test is a weight-(c+1) basic commutator. There is no random seed.
All runs used the recorded runner, one CPU slot and a 4 GB process limit.

| Recorded run | Limits | Outcome |
| --- | --- | --- |
| `f20-weight5-rewriting-v1` | 20,000 equations, stored length 50, 500,000 states | 128 retained rules; all nine targets reduce to identity; API reports false because the length restriction could discard equations |
| `f20-weight5-rewriting-unrestricted-length` | same bounds, no length restriction | Confluent system, API true, 128 rules, all nine targets reduce to identity: known positive control |
| `f20-weight6-rewriting-v1` | 20,000 equations, length 50, 500,000 states | Equation limit; 17,508 retained rules; ten of eighteen targets reduce to identity |
| `f20-weight6-rewriting-100k-len20` | 100,000 equations, length 20, 500,000 states | Equation limit; 100,000 retained rules; same ten targets reduce to identity |
| `f20-weight6-rewriting-100k-len100` | 100,000 equations, length 100, 500,000 states | State limit; 33,943 rules; subsequent word reduction raises a GAP method error; no target results |

Elapsed times were 2.03, 1.92, 6.24, 16.23 and 20.41 seconds respectively.
The last failed run has GAP exit status zero but lacks the expected
completion marker; the wrapper correctly records `process_ok=false`.
Its raw stderr and terminal bytes are preserved. The other stderr files
are empty.

The original script used by the first four chronologically executed
runs is preserved as `research/certificates/F20/probe-v1.g`; the current
script additionally permits disabling the stored-length bound. Complete
commands and bounds are in each run's `process.json`.

The eight nonempty reductions at weight six prove no nontriviality,
since the systems are not confluent. These experiments provide no new
F20 solution and are not counted as a partial candidate. Enlarging the
same rewriting budgets is presently a low priority.
